# BatteryAlert
### Simple (Linux) service that sends you a notification when you should disconnect your charger(>=95%).
Be aware that the install.sh script turns it into a service that will be always running on your PC.
## Installation
### Easiest way to install is to put the binary(from [releases](https://github.com/setLore/BatteryAlert/releases)) in the same folder as install.sh and run it as shown below.
### Run `chmod +x install.sh`
### Run `install.sh`
## UN-Installation
### Run `chmod +x uninstall.sh`
### Run `uninstall.sh`
